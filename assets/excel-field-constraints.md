# Excel 报告字段级约束

本文件定义 yonclaw-skill-acceptance Excel 报告中每个页签、每个字段的合法性约束。
`scripts/validate_excel_report.py` 会校验这些规则。

> **排除规则**：`目标确认`（TARGET）、`强制读取`（READ）、`结论门禁`（VERDICT）三类方法论大项的检查点**只进 `检查点自检` 页签**，不得出现在 `<skill-name>汇总` 或 `<skill-name>` 明细页中。

## 字段约束表

| 页签 | 字段 | 约束类型 | 合法值 / 规则 |
|------|------|----------|--------------|
| 汇总 | 技能清单 | 必填 | 非空字符串 |
| 汇总 | 测试点总数 | 必填 | ≥ 1 的整数 |
| 汇总 | 通过率 | 必填 | 0%~100%，公式计算 |
| `<skill-name>汇总` | 项目 | 必填 | 枚举（与 checkpoints.json category 一致，不含TARGET/READ/VERDICT/REPORT）：`BIP 规范专项检查`、`通用规范检查`、`安全与风险审计`、`异常输入与副作用审计`、`平台集成检查`、`功能清单与覆盖`、`动态用例结果`、`BIP 脚本合规检查`、`Baseline Failure` |
| `<skill-name>汇总` | 测试点总数 | 必填 | ≥ 1 的整数 |
| `<skill-name>` | 方法论大项 | 必填 | 与 checkpoints.json category 一致（不含 `目标确认`、`强制读取`、`结论门禁`、`报告交付自检`） |
| `<skill-name>` | 具体测试点 | 必填 | 非空字符串，不得写 `同上` 或 `...` |
| `<skill-name>` | 测试结果 | 必填·枚举 | 仅允许 `通过`、`不通过`、`未执行` |
| `<skill-name>` | 备注 | 条件必填 | 测试结果为 `不通过` 或 `未执行` 时必须填写原因/证据 |
| 检查点自检 | 检查点ID | 必填 | 与 checkpoints.json 中 ID 一致（含 TARGET/READ/VERDICT 全部 66 项） |
| 检查点自检 | 自检结果 | 必填·枚举 | 仅允许 `通过`、`未通过`、`阻塞`、`不适用` |
| 检查点自检 | 覆盖位置 | 条件必填 | 适用时必须指向具体页签!单元格，如 `skill-name!B12`，或 `未覆盖` |
| 检查点自检 | 备注 | 条件必填 | 自检结果为 `未通过` 或 `阻塞` 时必须填写原因 |

## 违反处理

- **必填字段为空**：报告标记为 `invalid`，须修正后重新生成
- **枚举字段值不在合法范围**：替换为最接近的合法值并在备注说明
- **通过率计算与明细不一致**：以明细为准重新计算
- **TARGET/READ/VERDICT 出现在明细页**：移至 `检查点自检` 页签，明细页对应行删除并重算统计
